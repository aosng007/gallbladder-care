胆囊切除术后女士低脂养护食谱

专为恢复期及胆道养护设计的低脂中西餐膳食指南

💡 核心饮食原则

1. 低脂清淡

每餐用油控制在 5-10g，避免油炸、重油爆炒，减少胆道负担。

2. 少食多餐

建议一日 3 正餐 + 1-2 次轻度加餐，帮助胆汁均匀排空。

3. 优质蛋白

优先选择蒸/煮鸡胸肉、深海白肉鱼、虾仁、蛋清及豆腐。

4. 可溶性高纤

多吃燕麦、山药、南瓜及新鲜蔬菜，吸附多余胆汁酸。

🍽️ 每日中西餐搭配食谱

🌅 早餐 (Breakfast)
🥢 中式方案
  • 山药大枣小米粥
  • 蒸蛋白 / 水煮蛋（去黄）
  • 蒸小馒头 / 花卷
  • 凉拌少油丝瓜 / 木耳
🍽️ 西式方案
  • 燕麦脱脂牛奶粥（配蓝莓/香蕉）
  • 全麦吐司（不抹黄油）
  • 蒸鸡胸肉薄片
☀️ 午餐 (Lunch)
🥢 中式方案
  • 清蒸黄花鱼 / 鲈鱼
  • 蒸南瓜山药
  • 蒜蓉清蒸西兰花（微油）
  • 紫菜蛋花汤 + 杂粮饭
🍽️ 西式方案
  • 香草清蒸 / 煎鸡胸肉（极少橄榄油）
  • 烤甜椒生菜沙拉（无油油醋汁/低脂酸奶酱）
  • 藜麦红薯饭 / 蒸烤马铃薯
🌙 晚餐 (Dinner)
🥢 中式方案
  • 豆腐虾仁青菜汤饭 或 鲜虾冬瓜豆腐煲
  • 清蒸丝瓜
  • 少量紫米饭
🍽️ 西式方案
  • 清蒸三文鱼 / 狭鳕鱼排（柠檬汁调味）
  • 蒸水煮西兰花与胡萝卜
  • 烤小土豆块
🍓 建议加餐 (Snacks)
  • 无糖 / 低脂酸奶（100-150ml）
  • 1 小把蓝莓 或 蒸熟苹果片

🏃‍♀️ 术后护理与生活建议

  • 餐后活动：进餐后建议顺时针轻柔按摩腹部 5-10 分钟，或进行 15-20 分钟的慢速散步，促进胃肠蠕动。
  • 充足饮水：保证每日饮水量在 1500 - 2000 毫升，帮助稀释胆汁。
  • 循序渐进：若某种食物引起腹泻或不适，暂停食用 1-2 周后再试。
⚠️ 医生特别提醒：
如出现右上腹剧烈疼痛、持续性恶心呕吐、发热或皮肤/眼睛发黄（黄疸）等症状，请务必及时前往医院急诊就诊。
